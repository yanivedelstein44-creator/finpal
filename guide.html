מדריך הקמה: FinPal משפחה

מקימים פעם אחת, בערך חצי שעה. אחר כך הכול עובד לבד, בשני הטלפונים.

אם האפליקציה כבר הועלתה וחוברה לגוגל בשבילכם (במסך "שמירה ב-Google Drive" כתוב שפרטי החיבור כבר מוגדרים), מדלגים ישר לשלב 3.

1. העלאת האפליקציה לאינטרנט (GitHub Pages, חינם) 2. חיבור ל-Google Drive 3. התקנה בשני הטלפונים אם משהו לא עובד

1. העלאת האפליקציה לאינטרנט

האפליקציה היא אתר קטן שמותקן בטלפון. היא צריכה כתובת קבועה באינטרנט. GitHub Pages נותן כתובת כזו בחינם. באתר יש רק את קוד האפליקציה, בלי שום נתון שלכם.

  1. במחשב, נכנסים ל-github.com ופותחים חשבון (אם אין). שם המשתמש יהיה חלק מהכתובת, למשל yaniv-e.
  2. לוחצים New repository. בשם כותבים finpal, משאירים Public, ולוחצים Create repository.
  3. בעמוד שנפתח לוחצים על הקישור uploading an existing file.
  4. פותחים את קובץ ה-zip שקיבלתם, נכנסים לתיקייה finpal, מסמנים את כל מה שבתוכה (Ctrl+A), וגוררים לחלון של GitHub. לוחצים Commit changes.
  5. עוברים ל-Settings ← Pages. תחת Branch בוחרים main ולוחצים Save.
  6. אחרי דקה-שתיים מופיעה למעלה הכתובת של האפליקציה, למשל https://yaniv-e.github.io/finpal/. רושמים אותה.

עדכון לגרסה חדשה בעתיד: אותו דבר, גוררים את הקבצים החדשים ל-Add file ← Upload files. הנתונים בטלפונים לא מושפעים.

חשוב: כל האתרים של אותו חשבון GitHub חולקים כתובת אחת (USERNAME.github.io), והדפדפן רואה בהם אתר אחד. לכן לא מפרסמים מאותו חשבון אתרים אחרים ב-GitHub Pages, ולא נותנים לאחרים הרשאת עריכה ל-repository. אתר אחר באותה כתובת יוכל לקרוא את מה שהאפליקציה שומרת בטלפון.

2. חיבור ל-Google Drive

כדי שהאפליקציה תוכל לשמור קובץ מוצפן בדרייב שלכם, יוצרים לה "זהות" בחשבון הגוגל שלכם. בסוף יהיו לכם שני ערכים: מזהה לקוח ומפתח API. את שניהם מדביקים באפליקציה.

הכתובות שתצטרכו (מתמלאות לבד כשפותחים את המדריך מתוך האפליקציה):
מקור: https://USERNAME.github.io
כתובת האפליקציה: https://USERNAME.github.io/finpal/

א. פרויקט

  1. נכנסים ל-console.cloud.google.com עם חשבון הגוגל שלך, ומאשרים את התנאים אם צריך.
  2. למעלה, ליד הלוגו, לוחצים על בחירת הפרויקט ← New project. שם: FinPal ← Create. מוודאים שהפרויקט החדש נבחר.

ב. הפעלת Google Drive API

  1. בשורת החיפוש למעלה כותבים Google Drive API, ובוחרים אותו.
  2. לוחצים Enable.

ג. מסך ההסכמה (Google Auth Platform)

  1. בחיפוש כותבים Google Auth Platform ונכנסים. לוחצים Get started.
  2. שם האפליקציה: FinPal משפחה. אימייל לתמיכה: האימייל שלך ← Next.
  3. Audience: בוחרים External ← Next. אימייל ליצירת קשר: שוב שלך ← Next. מסמנים הסכמה ← Create.
  4. בתפריט הצד: Audience ← Publish app ← Confirm. האפליקציה מבקשת רק גישה לקבצים שהיא עצמה יוצרת, ולכן גוגל לא דורשת אימות. (אפשרות אחרת: להשאיר במצב Testing ולהוסיף תחת Test users את האימיילים של שניכם.)
  5. בתפריט הצד: Data Access ← Add or remove scopes. בחיפוש כותבים drive.file, מסמנים את השורה .../auth/drive.file ← Update ← Save.

ד. מזהה הלקוח (Client ID)

  1. בתפריט הצד: Clients ← Create client.
  2. Application type: Web application. שם: FinPal.
  3. תחת Authorized JavaScript origins ← Add URI, ומדביקים את המקור: https://USERNAME.github.io (בלי לוכסן בסוף).
  4. תחת Authorized redirect URIs ← Add URI, ומדביקים את כתובת האפליקציה: https://USERNAME.github.io/finpal/ (עם לוכסן בסוף).
  5. Create. מעתיקים את ה-Client ID (נגמר ב-apps.googleusercontent.com). את ה-Client secret לא צריך.

ה. מפתח ה-API

  1. בחיפוש כותבים Credentials ונכנסים ל-APIs & Services ← Credentials.
  2. Create credentials ← API key. מעתיקים את המפתח (מתחיל ב-AIza) ולוחצים Edit API key.
  3. תחת Application restrictions בוחרים Websites ← Add, ומקלידים: https://USERNAME.github.io/*
  4. תחת API restrictions בוחרים Restrict key, ומסמנים רק את Google Drive API. Save.

זהו. את שני הערכים מדביקים באפליקציה, בשלב "שמירה ב-Google Drive" (או אחר כך: עוד ← פרטי החיבור לגוגל).

3. התקנה בשני הטלפונים

הטלפון שלך

  1. פותחים בכרום את כתובת האפליקציה ולוחצים הורדת האפליקציה לאנדרואיד. פותחים את הקובץ FinPal.apk שהורד ומאשרים התקנה. בפעם הראשונה אנדרואיד מבקש לאשר התקנה מכרום: מאשרים וחוזרים. מעכשיו פותחים את FinPal מהמסך הבית, והיא מתעדכנת לבד.
  2. לוחצים מתחילים: שמות, קוד נעילה, קוד שחזור (שומרים אותו!), ואז מדביקים את שני הערכים ומתחברים לגוגל.
  3. במסך של גוגל מסמנים את התיבה שמאשרת גישה לקבצים של FinPal. אם מופיע "Google hasn't verified this app", לוחצים Advanced ← Go to FinPal: זו האפליקציה שלכם.
  4. מזמינים את בן/בת הזוג: נשלח קישור בוואטסאפ, ואת הקוד אומרים בעל פה.

הטלפון של בן/בת הזוג

  1. פותחים את הקישור מוואטסאפ (בכרום), מקלידים את הקוד ובוחרים קוד נעילה. את האפליקציה מורידים מאותו מקום: עוד ← הורדת האפליקציה לאנדרואיד.
  2. כבר עכשיו רואים את כל הנתונים. כדי לייבא קבצים גם מהטלפון הזה, מתחברים לגוגל פעם אחת, ושולחים קישור חיבור (האפליקציה תציע).

ייבוא קבצים

מורידים קובץ תנועות מאתר לאומי או MAX, ואז באפליקציה לוחצים על כפתור הייבוא, או בתיקיית ההורדות: לחיצה ארוכה על הקובץ ← שיתוף ← FinPal.

אם משהו לא עובד

  1. redirect_uri_mismatch: הכתובת שנרשמה בשלב ד' לא זהה בדיוק לכתובת האפליקציה. בודקים https, אותיות קטנות, ולוכסן בסוף.
  2. access_blocked או Access denied: האפליקציה במצב Testing, והאימייל לא ברשימת Test users. מוסיפים אותו, או לוחצים Publish app.
  3. "צריך לסמן את האישור": במסך של גוגל לא סומנה התיבה של הגישה לקבצים. מתחברים שוב ומסמנים.
  4. "גוגל סירבה לבקשה": בודקים ש-Google Drive API מופעל (שלב ב'), ושבמפתח ה-API הכתובת בשלב ה' נכונה.
  5. שכחתי את קוד הנעילה: עוד ← מחיקת הנתונים מהטלפון, ואז נכנסים עם קוד השחזור (או עם הזמנה חדשה). מה שבדרייב לא נמחק.

FinPal משפחה לא מתחברת לבנק ולא לחברות האשראי, ואין לה שרת. הנתונים שמורים בטלפונים, ובדרייב נשמר רק קובץ מוצפן. מדיניות הפרטיות
