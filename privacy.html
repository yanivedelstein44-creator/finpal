מדיניות פרטיות: FinPal משפחה

עודכן: נובמבר 2026

FinPal משפחה היא אפליקציה פרטית לניהול הכסף של משפחה אחת: שני בני זוג רואים את אותם נתונים, כל אחד בטלפון שלו. לאפליקציה אין שרת, אין בה פרסומות, ואין בה כלי מעקב או סטטיסטיקה.

אילו נתונים האפליקציה קוראת

  • קבצי תנועות מהבנק או מכרטיסי האשראי, שהורדתם בעצמכם ובחרתם לייבא. האפליקציה לא מתחברת לבנק או לחברות האשראי, ולא מבקשת סיסמאות שלהם.
  • Google Drive, רק באישור שלכם: הרשאה מסוג drive.file, שנותנת גישה רק לקבצים שהאפליקציה עצמה יצרה. האפליקציה לא רואה שום קובץ אחר בדרייב.
  • כתובת האימייל של חשבון הגוגל: מוצגת באפליקציה כדי שתדעו לאיזה חשבון היא מחוברת, ומשמשת להצעת אותו חשבון בהתחברות הבאה.

איפה הנתונים נשמרים

  • בטלפון: באחסון של הדפדפן בטלפון בלבד. אפשר לנעול את האפליקציה בקוד.
  • ב-Google Drive של כל אחד מבני הזוג: קובץ אחד, מוצפן (AES-256-GCM). המפתח נמצא רק בשני הטלפונים של המשפחה ובקוד השחזור שלה. לגוגל ולכל מי שאין לו את המפתח, הקובץ הוא רצף תווים חסר משמעות.
  • כדי שהטלפון של בן/בת הזוג יוכל לקרוא את הקובץ, הוא משותף בקישור ("כל מי שיש לו את הקישור"). הקישור לא מתפרסם בשום מקום, ובלי המפתח אי אפשר לפתוח את התוכן.

עם מי הנתונים משותפים

עם אף אחד. המידע מ-Google לא נמכר, לא מועבר לאף גורם, ולא משמש לפרסום או לשום מטרה מלבד הצגת הנתונים של המשפחה לשני בני הזוג. מי שבנה את האפליקציה לא מקבל שום נתון. השימוש במידע שמתקבל מ-Google APIs עומד ב-Google API Services User Data Policy, כולל דרישות ה-Limited Use.

האתר עצמו מאוחסן ב-GitHub Pages. כמו כל אתר, GitHub עשויה לרשום מידע טכני על הגישה לאתר (למשל כתובת IP), לפי מדיניות הפרטיות שלה. הנתונים הכספיים לא עוברים דרך GitHub.

מחיקה וביטול גישה

  • מחיקה מהטלפון: באפליקציה, עוד ← מחיקת הנתונים מהטלפון הזה.
  • מחיקה מהדרייב: מוחקים ב-Google Drive את הקובץ שמתחיל ב-FinPal.
  • ביטול הגישה לדרייב: בדף ההרשאות של חשבון הגוגל, myaccount.google.com/permissions, בוחרים ב-FinPal ומסירים את הגישה.

לשאלות על האפליקציה פונים למי ששלח לכם את הקישור אליה.

Privacy policy (English summary)

FinPal Family is a private budgeting app for one household. It has no server, no ads and no analytics.

  • It reads only bank and credit card statement files that the user downloads and chooses to import. It never connects to a bank.
  • With the user's consent it uses the Google Drive drive.file scope, which gives access only to files the app itself created, and the account's email address (shown in the app and used as a sign-in hint).
  • Each partner's Drive holds one file encrypted with AES-256-GCM. The key exists only on the family's two phones and in their recovery code. The file is shared by link so the partner's phone can download it; without the key its content cannot be read.
  • Google user data is not sold, transferred or used for advertising or any purpose other than showing the household's data to its two members. FinPal Family's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Users can delete local data in the app (More, then delete data from this phone), delete the Drive file, and revoke access at myaccount.google.com/permissions.
