# FinPal משפחה

האתר של אפליקציית FinPal משפחה: ניהול הכסף של הבית בשני טלפונים, עם קבצים מהבנק (לאומי) ומכרטיסי האשראי (MAX).

- אין כאן שום נתון של המשפחה. הנתונים נשמרים בטלפונים, ובכל Google Drive נשמר רק קובץ מוצפן.
- האפליקציה לא מתחברת לבנק ואין לה שרת. היא קוראת רק קבצים שהורדתם בעצמכם.
- מדריך ההקמה המלא נמצא באפליקציה עצמה, בקובץ `guide.html`. מדיניות הפרטיות: `privacy.html`.
- **חשוב:** כל האתרים של אותו חשבון GitHub חולקים כתובת אחת (`USERNAME.github.io`), והדפדפן רואה בהם אתר אחד. לכן לא מפרסמים מהחשבון הזה אתרים אחרים ב-GitHub Pages, ולא נותנים לאחרים הרשאת עריכה ל-repository. היוצא מן הכלל: `yanivedelstein44-creator.github.io`, שיש בו רק את קובץ האימות של אפליקציית האנדרואיד (`.well-known/assetlinks.json`), בלי קוד.

עדכון לגרסה חדשה: **Add file** ← **Upload files**, גוררים את כל הקבצים מהגרסה החדשה, ו-**Commit changes**.
